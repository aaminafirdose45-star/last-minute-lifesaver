# ⚡ Last-Minute Lifesaver

> An AI-powered deadline rescue companion that doesn't just remind you — it actively plans, reschedules, and pushes you to finish before deadlines hit.

## 🌐 Live Demo
[last-minute-lifesaver.vercel.app](https://last-minute-lifesaver.vercel.app)

## 🎯 Problem Statement
Students, professionals, and entrepreneurs frequently miss deadlines, assignments, meetings, and important commitments. Existing productivity tools rely on passive reminders that are easy to ignore.

## 💡 Solution
Last-Minute Lifesaver is an AI productivity companion that proactively assists users in planning, prioritizing, and completing tasks before deadlines are missed.

## ✨ Key Features
- **AI Task Analysis** — Gemini analyzes urgency, estimates time, breaks into steps
- **Live Countdown Timer** — Real-time ticking countdown on every task
- **🚨 Rescue Mode** — AI emergency plan when you're overwhelmed
- **🤖 AI Assistant** — 4 instant AI advice modes powered by Gemini
- **XP & Level System** — Gamified productivity tracking
- **🏆 Badges** — 6 unlockable achievement badges
- **Google Sign-in** — Secure Firebase authentication
- **Cloud Sync** — Tasks saved to Firebase Firestore

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **AI:** Google Gemini 2.0 Flash API
- **Database:** Firebase Firestore
- **Auth:** Firebase Authentication (Google Sign-in)
- **Deployment:** Vercel

## 🔵 Google Technologies Used
- Google Gemini 2.0 Flash (AI analysis, rescue mode, assistant)
- Firebase Firestore (real-time database)
- Firebase Authentication (Google OAuth)
- Google AI Studio (API key management)
